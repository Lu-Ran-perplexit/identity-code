<h1 align="center">身份码</h1>

<p align="center">一个用来打开取件身份码的 Android 小工具</p>

<p align="center">
  <a href="https://github.com/Lu-Ran-perplexit/identity-code/releases/latest"><strong>下载 Android 版</strong></a> · Android 8.0 及以上
</p>

到了驿站，轮到你出示身份码时，打开「身份码」，点对应的平台即可。适合经常在多个平台取件、想少翻几层菜单的人。适合中国大学生。取件身份码在对应平台 App 内显示。

## 安装与使用

1. 到[发布页](https://github.com/Lu-Ran-perplexit/identity-code/releases/latest)的 **Assets** 下载 `identity-code-1.0.0.apk`。
2. 打开 APK，按手机提示安装。使用前请在手机上安装并登录对应平台 App。
3. 在「身份码」里点菜鸟、淘宝或拼多多。若平台直达入口不可用，可以在对应平台 App 内查找身份码。
